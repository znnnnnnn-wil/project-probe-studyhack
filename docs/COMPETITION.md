# StudyHack 参赛准备

**作品** 项目追问官 · **赛道** StudyHack 学习科研

帮助准备技术实习的学生，围绕项目材料练习连续追问，在复盘里回看自己的回答和改进建议。

**[在线体验](https://project-probe-ooc80l33zpz.qoder.website/)** · [官方赛事介绍](https://tianchi.aliyun.com/competition/entrance/532536/introduction) · [官方提交清单](https://tianchi.aliyun.com/competition/entrance/532536/information)

## 三分钟演示

1. **0:00–0:25** 用预约系统举例。简历写了「避免重复占座」，面试时还需要说清约束放在哪里、冲突如何处理、自己如何验证。
2. **0:25–1:05** 打开公开站点，选择「校园自习室预约系统」，点击「开始五轮练习」和「同意并开始语音面试」。
3. **1:05–1:50** 展示数字人提问和语音回答。也可以点击「发送参考回答」演示提交与下一轮衔接。
4. **1:50–2:40** 从同一浏览器的训练记录打开一轮已完成的示例。展示原回答、优先改进项和评分依据。如果报告提供专项复测入口，演示补答前后对照。
5. **2:40–3:00** 展示一轮真实的 Qoder 开发或调试记录和公开发布状态，说明项目沿用部分、本轮修改和验收结果。

## 当前公开版本

- 首页和示例练习可免登录访问。自有项目练习需要登录。
- 公开前端发布在 Qoder Sites，独立的 Spring Boot 服务处理模型、语音和训练记录。评委体验用预置的合成项目材料即可。
- 2026 年 11 月 23 日，以独立访客打开线上语音面试，使用示例参考回答完成五轮，并在复盘页看到「导出本轮复盘」入口。

## 发帖材料

- 标题标明 `【StudyHack】`。正文包含公开作品网址和实际使用的 Qoder 账号 UID。
- 写清自我介绍、作品是什么、为什么做、五步以内的使用方式和 Qoder 开发过程。产品截图可选首页、面试室和复盘三张。
- 开发记录贴对应的 Qoder 对话或调试截图，写明需求、改动和验证结果。部署证据使用实际的公开发布截图。沿用的项目基础见[初始迁移记录](MIGRATION.md)。
- 在[比赛论坛](https://tianchi.aliyun.com/competition/entrance/532536/forum)发布并查看审核状态。报名及实名、大学生认证要求见[官方 FAQ](https://tianchi.aliyun.com/competition/entrance/532536/customize917)。
